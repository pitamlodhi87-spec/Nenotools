  ➜ Open your browser and go to: http://localhost:8000

To change colors:
  1. Open "styles.css" in a text editor
  2. Find the ":root {" section at the top
  3. Modify the color values (e.g., --primary-color: #your-color)
  4. Save the file
  5. Refresh your browser

Available color variables:
  --primary-color      (Default: #6366f1 - Indigo)
  --secondary-color    (Default: #ec4899 - Pink)
  --success-color      (Default: #10b981 - Emerald)
  --warning-color      (Default: #f59e0b - Amber)
  --danger-color       (Default: #ef4444 - Red)
