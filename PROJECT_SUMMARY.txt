🚀 HOW TO GET STARTED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option 1: Direct File Opening (Simplest)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Open index.html directly in your browser
  2. Click on any tool card to start using it

Option 2: Local Server (Recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Using Python 3:
    $ cd /workspaces/Nenotools
    $ python -m http.server 8000
    Open: http://localhost:8000

  Using Node.js:
    $ cd /workspaces/Nenotools
    $ npx http-server
    Open: http://localhost:8080

  Using PHP:
    $ cd /workspaces/Nenotools
    $ php -S localhost:8000
    Open: http://localhost:8000

  1. Open styles.css
  2. Find :root section
  3. Modify --primary-color, --secondary-color, etc.
  4. Save and refresh browser

To add new tools:
  1. Create new HTML file with same structure
  2. Copy navigation and footer from existing tools
  3. Add your tool-specific HTML
  4. Link styles.css and script.js
  5. Add tool card to index.html
